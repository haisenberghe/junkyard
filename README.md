# Junkyard prototype

A static, mobile-friendly concept for booking towable trailer stays, local tours, and pop-up cinema events around Kenya.

## Preview

Open `index.html` in a browser. Listings, locations, prices, and event dates are sample content. The booking form is a demo only; it does not collect or save bookings or payments.

## Included

- Junkyard vector logo with a mountain, sunset, towable cabin, and cactus
- Photo-led hero using the provided highland landscape
- Browse and filter stays and tours
- Search sample listings by location
- View pop-up cinema listings
- Demo booking request flow
- Responsive layout for phone and desktop

This is a visual prototype. It does not include user accounts, live availability, a database, payment processing, or a host dashboard.
