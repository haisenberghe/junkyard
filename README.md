# Junkyard prototype

A static, mobile-friendly concept for booking towable bus stays, local tours, and pop-up cinema events around Kenya.

## Preview

Open `index.html` in a browser. Listings, locations, prices, and event dates are sample content for demonstration. The booking form is a demo only; it does not collect or save bookings or payments.

## Included in this prototype

- Photo-led design using the provided Kenyan highland landscape
- Browse and filter stays and tours
- Search sample listings by location
- View pop-up cinema listings
- Try the demo booking request flow
- Responsive layout for phone and desktop

This first version is a visual prototype. It does not include user accounts, live availability, a database, payment processing, or an operational host dashboard.
